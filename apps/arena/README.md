# Arena page (placeholder build)

Single-file blind-battle UI: type a line, two anonymous tools say it (browser
speech synthesis stands in for vendor APIs), vote, reveal, Elo, jury scorecard,
share card, leaderboard. Ten fictional tools. Published as a Claude artifact for
review; the static site in `apps/site` is the production surface and will grow
this UI once real executions exist.

The file has no `<html>/<head>/<body>` wrapper because the artifact host adds
one. To view locally, wrap it or open it via a tiny shim.
